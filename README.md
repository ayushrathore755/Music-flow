# MusicFlow

A vintage vinyl-style music player web app built with HTML, CSS and vanilla JavaScript.

## Features

- Play, pause, next, previous, shuffle and repeat (off / all / one)
- Playlist management: add multiple songs, click to play, remove songs
- Live song info, seek bar with timer and volume control
- Spinning record and moving tonearm animation, smooth track transitions
- Audio visualizer using the Web Audio API
- Volume, shuffle and repeat settings saved with localStorage
- Responsive layout for mobile and desktop
- Keyboard shortcuts: Space (play/pause), Left and Right arrows (previous/next)

## Tech Stack

HTML5, CSS3, JavaScript , Web Audio API, localStorage

## How to Use

1. Open the live demo or run index.html in your browser
2. Click "+ Add Song" and choose audio files from your computer
3. Press play and enjoy
